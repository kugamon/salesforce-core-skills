# sf-campaigns

Analyze Salesforce campaign performance via any Salesforce MCP server — funnels, conversion rates, ROI, cost per lead, and invest/pause recommendations with the math shown.

## What it does

| Action | Description |
| --- | --- |
| `report` | Portfolio view of active campaigns ranked by ROI/pipeline |
| `analyze` | Single-campaign deep dive: funnel, response timing, influenced opportunities |
| `compare` | Cross-campaign ranking, lead-source and campaign-type patterns |

Flags missing-cost campaigns as data hygiene findings instead of mis-ranking them, and distinguishes primary-source vs influence attribution.

## Examples

- "Which campaigns are actually working?"
- "Deep dive on the Q2 webinar series campaign"
- "Rank my campaigns by cost per lead"
